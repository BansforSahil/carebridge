# CareBridge — AI Healthcare Awareness & Access

CareBridge is a multilingual AI healthcare awareness assistant built with a **React + TypeScript** frontend and a **Flask + LangChain/Groq** backend. It lets users ask health questions in English or Hindi, analyse medicine images, and find nearby healthcare resources — all through a clean, accessible UI.

---

## Features

- 💬 **AI Chat** — Ask healthcare questions in English or Hindi, powered by Groq LLM
- 🎤 **Voice Input** — Speak your question using the mic button; the AI reads the answer aloud
- 📷 **Medicine Image Analysis** — Upload a photo of a medicine/tablet and get a plain-language explanation
- 🌐 **Multilingual** — English and Hindi supported for both input and spoken output
- 🔍 **Resource Finder** — Find nearby hospitals, clinics, and health centres
- 🧠 **Conversation Memory** — The assistant remembers context within a session

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/carebridge.git
cd carebridge
```

### 2. Create your `.env` file

Create a file called `.env` in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

> **Never commit your `.env` file.** It is already in `.gitignore`.

### 3. Run the project

```bash
python run.py
```

That's it. `run.py` will automatically:
1. Create a Python virtual environment (`.venv/`) if one doesn't exist
2. Install all Python dependencies from `requirements.txt`
3. Install frontend Node.js packages (`npm install`)
4. Build the React frontend (`npm run build`) → outputs to `frontend_dist/`
5. Open `http://localhost:5000` in your browser
6. Start the Flask server

> **Important:** Always open the app at `http://localhost:5000` (not your machine's IP address). Voice input requires a secure context — `localhost` qualifies, a plain `http://` IP address does not.

## Running in Development Mode (optional)

If you want live-reload for frontend changes, run the Flask backend and Vite dev server separately:

**Terminal 1 — Flask backend:**
```bash
python webapp.py
```

**Terminal 2 — Vite frontend:**
```bash
cd frontend
npm install
npm run dev
```

Then open `http://localhost:5173`. The Vite dev server proxies all `/api/*` requests to Flask on port 5000.

## Voice Feature Notes

- Voice input uses the browser's **Web Speech API** — works in Chrome and Edge only (not Firefox)
- The mic button must be **allowed** in browser settings (`🔒 lock icon → Microphone → Allow`)
- **Hindi TTS (text-to-speech)** requires a Hindi voice installed on your OS:
  - Windows: Settings → Time & Language → Language → Add Hindi → install **Microsoft Heera** or **Microsoft Hemant**
  - Without a Hindi voice, the browser will not speak Hindi responses

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/chat` | Send a chat message, get AI response |
| `POST` | `/api/analyze-image` | Upload a medicine image for analysis |
| `GET` | `/api/resources` | Search nearby healthcare resources |
| `POST` | `/api/clear` | Clear the server-side conversation history |
